# 이터널리턴 스크림·대회 점수판

인게임 결과 CSV(GameResult_.csv)를 업로드해 라운드별 점수를 자동 집계하는 비공개 점수판입니다.
생성할 때 **스크림**과 **대회** 중 하나를 고릅니다.

- **스크림**: CSV 업로드, 패널티, 팀명 수정, 리플레이 게임 ID, 디스코드용 복사 — 가벼운 기본 기능
- **대회**: 스크림 기능 전부 + 실시간 점수 입력, 스크린샷 TS 인식(OCR), OBS 오버레이, 결과 그래픽. 생성 시 **Team 1~8이 자동 등록**되며(8팀 고정), 팀명 수정(✎)으로 실제 팀 이름을 넣어 쓰세요. 잘못 만진 팀은 팀 행을 펼쳐 **팀 초기화**로 되돌릴 수 있어요. 이름을 안 바꿔둔 기본 팀(Team N)은 첫 CSV 업로드 때 CSV의 팀명으로 자동 전환됩니다

공통 사항:

- 팀당 `tournament total score`를 한 번씩만 합산
- 팀명이 판마다 바뀌어도 닉네임 2명 이상 일치로 같은 팀 인식
- 추측 불가능한 전용 URL, 검색엔진 비노출
- 관리 PIN으로만 업로드·패널티·팀명 수정 가능
- 디스코드에 링크를 올리면 현재 순위가 임베드로 표시
- 잘못 등록한 팀은 팀 행을 펼쳐 정리 — 스크림은 **팀 삭제**, 대회는 **팀 초기화**(자리는 유지하고 새 Team N으로 교체). 라운드 점수·패널티도 함께 삭제됩니다

## 라운드 진행 중 실시간 점수 (대회 전용)

CSV는 라운드가 끝나야 나오므로, 진행 중에는 관리자가 점수를 직접 올릴 수 있습니다.

- 관리자 화면의 **실시간 점수** 카드에서 라운드 번호를 정하고 시작 → 팀별 −0.5/+0.5 버튼 또는 직접 입력 (점수는 항상 0.5점 단위로 스냅)
- 입력은 로컬 초안에만 저장되고, **[점수 반영] 버튼을 눌러야** 시청자·OBS에 송출됩니다 (미반영 변경은 배지로 표시)
- **📷 스크린샷 인식**: 관전 화면(16:9 전체 캡처)을 드래그하거나 Ctrl+V로 붙여넣으면 하단 팀 카드의 TS 점수를 브라우저 안에서 OCR로 인식합니다 (Tesseract.js — 서버 전송 없음). 팀명은 인식하지 않고 왼쪽 칸부터 1팀 → 8팀 순서 그대로 반영하므로, 점수판의 팀 순서를 인게임 슬롯 순서와 맞춰 등록해 두세요. 인식 결과는 표에서 검토·수정 후 반영
- 팀별 💀 버튼으로 해당 라운드 **탈락(Terminate)** 을 표시할 수 있습니다 — 점수는 유지되고, 점수판·OBS에서 음영 처리됩니다
- KS는 실시간 집계로는 올라가지 않습니다 — **CSV를 업로드해야만 KS가 업데이트**됩니다
- 실시간 점수는 모든 시청자·OBS 오버레이에 15초 이내 반영되며, 표에는 🔴 표시로 "미확정"임을 구분
- 라운드가 끝나면 **같은 라운드 번호로 CSV를 업로드**하면 실시간 점수가 공식 기록으로 대체(확정)됩니다. CSV 없이 "이 점수로 확정"을 눌러 수기 확정할 수도 있어요 (✎ 표시)
- CSV 확정 라운드는 TS(`tournament total score`)와 별도로 KS(`tournament kill score`)도 집계되어 점수표와 결과 그래픽에 **KS 열**로 표시됩니다 (실시간 집계 중에는 TS만 입력)

## OBS 브라우저 소스 (대회 전용)

`https://.../b/점수판코드/obs` 를 OBS 브라우저 소스로 추가하면 투명 배경 순위표가 나옵니다 (헤더의 **OBS 소스 복사** 버튼 — 누구나 복사 가능).

- 권장 크기: **380 × 400** (8팀·scale 1 실측 기준, `?rounds=1`이면 라운드당 폭 +30px, `?scale`에 비례 확대) / 기본 5초마다 자동 갱신, 진행 중 점수 포함
- 열람용 API 응답은 Vercel 엣지에서 2초간 캐시되므로 시청자·OBS가 많아도 함수 호출과 Redis 사용량이 거의 늘지 않습니다 (무료 티어로 대회 운영 가능)
- 순위가 바뀌면 행이 부드럽게 자리를 바꾸고 ▲▼ 표시와 점수 하이라이트가 몇 초간 나타납니다
- 실시간 집계에서 💀(탈락) 표시된 팀은 음영 처리로 해당 라운드 탈락임을 보여줍니다 (해골 아이콘 없이 음영만)
- 상단에는 현재 라운드(ROUND N)와 LIVE 표시만 나옵니다 (제목 없음)
- URL 옵션: `?rows=8` 상위 N팀만 · `?rounds=1` 라운드별 점수 표시 · `?title=0` ROUND 표시줄 숨김 · `?scale=1.2` 배율 · `?poll=1` 갱신 주기(초, 1~30)

## 결과 그래픽 (대회 전용)

`https://.../b/점수판코드/graphic` (헤더의 **결과 그래픽** 버튼)에서 시상대 스타일로 디자인된 1600×900 결과 점수표를 볼 수 있고, **PNG로 저장** 버튼으로 고해상도(3200×1800) 이미지를 내려받아 디스코드 공지 등에 쓸 수 있습니다.

## 배포 방법 (Vercel + Upstash Redis, 무료)

### 1. GitHub에 올리기

```bash
cd er-scrim-board
git init
git add .
git commit -m "scrim board"
```

GitHub에서 새 저장소를 만든 뒤(비공개 권장):

```bash
git remote add origin https://github.com/내아이디/er-scrim-board.git
git branch -M main
git push -u origin main
```

### 2. Vercel에 배포

1. https://vercel.com 에 GitHub 계정으로 로그인
2. **Add New → Project** → 방금 올린 저장소 **Import**
3. 설정은 그대로 두고 **Deploy** (이 시점엔 DB가 없어 페이지가 오류나도 정상)

### 3. Upstash Redis 연결

1. Vercel 프로젝트 → **Storage** 탭 → **Create Database** → **Upstash for Redis** 선택
2. 무료 플랜으로 생성하고 프로젝트에 **Connect**
3. 환경 변수(`KV_REST_API_URL`, `KV_REST_API_TOKEN` 등)가 자동 주입됩니다
4. **Deployments** 탭에서 최신 배포의 ⋯ 메뉴 → **Redeploy**

### 4. 사용

1. `https://프로젝트명.vercel.app` 접속 → 스크림 이름 + 관리 PIN 입력 → 점수판 생성
2. 발급된 `/b/무작위코드` 링크를 디스코드에 공유
3. 매 라운드가 끝나면 CSV를 드래그해서 업로드

## 로컬 개발

`.env.local` 파일에 Upstash 콘솔의 REST 정보 입력:

```
UPSTASH_REDIS_REST_URL=...
UPSTASH_REDIS_REST_TOKEN=...
```

```bash
npm install
npm run dev
```
